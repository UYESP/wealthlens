# WealthLens — Contexto de proyecto

## Al iniciar cada sesión, ejecuta esto primero:
1. Lee `docs/WealthLens_Plan_Aprendizaje_v2.md`
2. Lee `docs/CHANGELOG.md`
3. Ejecuta `git log --oneline -15`

Luego confirma el módulo actual y el último progreso antes de continuar.

## Stack
- Frontend: React 18 + Vite + Tailwind v4 + Shadcn/ui
- Backend: Azure Functions + Node.js
- Auth: Azure AD B2C
- DB: Azure Cosmos DB
- Hosting: Azure Static Web Apps + GitHub Actions

## Convenciones de commits
- `feat(M2): descripción` — nueva funcionalidad
- `fix: descripción` — corrección
- `arch: descripción` — decisión de arquitectura
- `docs: descripción` — documentación
