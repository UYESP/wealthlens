# WealthLens

Aplicación de gestión de cartera financiera e inmobiliaria.

## Stack

| Capa | Tecnología |
|------|-----------|
| Frontend | React + Vite |
| Backend | Azure Functions (Node.js) |

## Estructura del repositorio

```
wealthlens/
├── frontend/       # App React + Vite
├── backend/        # Azure Functions (Node.js)
└── docs/           # Documentación del proyecto
```

## Inicio rápido

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

```bash
cd backend
npm install
func start
```

## Requisitos previos

- Node.js 20+
- Azure Functions Core Tools v4
- Azure CLI (para despliegue)
